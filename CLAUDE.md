# Asantico CLI, Project Context for Claude Code

## What this project is
A command-line tool that generates professional PDF invoices and estimates for **Asantico**, a Seattle property maintenance business. It replaces a one-off Python script with a structured, testable CLI suitable for daily operational use.

The primary user is the Asantico operator (Eyob "Stark" Worku). The primary recipient of generated PDFs is **Avenue One Residential** (contacts: Andrew Miller, Saniya Zaveri).

## Tech stack
- **Language:** Python 3.13
- **CLI framework:** Typer (built on Click)
- **PDF rendering:** ReportLab
- **Terminal UX:** Rich (for tables, color, prompts)
- **Testing:** pytest
- **Package layout:** `src/asantico_cli/` (src layout)

## Domain rules, non-negotiable

1. **Sales tax: Seattle rate of 10.55%** applied to every line item, including labor-only line items. Tax is calculated per-line and summed, not applied once to the subtotal. Display tax as a separate row beneath the subtotal.
2. **Two document types:** `invoice` (work completed, payment due) and `estimate` (work proposed, not yet billable). They share 90% of layout but differ in title, footer text, and the presence of payment terms.
3. **Line items** have: description (concise, no em dashes), quantity, unit (`hr`, `each`, `flat`), unit price, and computed line total (qty x price).
4. **No em dashes anywhere** in generated PDFs or in any text Claude writes for this project. Use commas, semicolons, or periods.
5. **Properties** are real Avenue One locations. Common ones: Garden, The Meridian, Portal, Aprea View, Gilman's Fairway, Linden Avenue Condominiums, Canterbury Shores, Koda Condominiums, Clark Roadhouse. The CLI must let the user pick from a configured list or enter a new one.
6. **Output directory:** PDFs land in `./output/` by default, named `{type}_{property-slug}_{YYYY-MM-DD}.pdf`.
7. **Currency:** USD, formatted as `$1,234.56` (commas, two decimals).

## Email and communication conventions (for any prose Claude generates)
- Short emails: scope and PDF attachment reference only, no pricing in the email body.
- Addressed to Andrew Miller or Saniya Zaveri depending on the property.
- No em dashes. No marketing language. Concise.

## Code conventions
- Type hints on every function.
- Docstrings on every public function (one-line summary plus Args and Returns).
- Pure functions where possible; keep PDF rendering isolated from business logic.
- Tests live in `tests/`, mirror the package structure, use pytest.
- No global state. Pass config explicitly.
